# Contributing

Thanks for your interest! The project is in the design stage.

## Right now

- **Feedback on the design:** read [docs/SPEC.md](docs/SPEC.md) and open an issue with suggestions or concerns.
- **Source changes:** if a data source in [docs/sources-findings.md](docs/sources-findings.md) has changed behaviour, please open an issue.

## Later

Once the catalog exists, you'll be able to suggest repos through an issue template. Each suggestion is checked against the inclusion criteria in [SPEC §8.2](docs/SPEC.md#82-inclusion-criteria).

## Development

- Node ≥ 20, no npm dependencies.
- Run tests: `npm test`
